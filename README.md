# AI Concepts Game 🎮🧠

[![License: Custom](https://img.shields.io/badge/license-Restricted-red.svg)](./LICENSE)

**AI Concepts Game** is an interactive, educational web application designed to help students and developers visualize complex **Artificial Intelligence (AI)** algorithms and core concepts from search, planning, and game theory by using engaging, hands-on simulations.

👉 **Live Website:** [https://AyanMemon296.github.io/AI-Concepts-Games/](https://AyanMemon296.github.io/AI-Concepts-Games/)

---

## 🔬 Simulation Modules (Features)

The project currently contains **8 verified and fully interactive simulation modules** that cover core AI concepts:

| Module | Concept Demonstrated |
| :--- | :--- |
| **Tic-Tac-Toe (Minimax)** | Play against an AI that uses the Minimax algorithm. Can you win? |
| **8-Puzzle** | Slide the tiles to solve the puzzle. A classic example of heuristics and A* search. |
| **Water Jug Problem** | A classic state-space search problem. You can measure exactly 2L using only 5L and 4L jugs. |
| **Missionaries & Cannibals** | Move 3 missionaries and 3 cannibals across a river. Don't let the cannibals outnumber the missionaries! |
| **Monkey & Banana Problem** | Help the monkey get the bananas using a box. A simple problem for planning algorithms. |
| **Tower of Hanoi** | Solve the recursive puzzle by moving disks between three pegs, following the rules. |
| **Hill Climbing Visualizer** | Watch an agent get stuck on local maxima while trying to find the highest point in a landscape. |
| **Tree Search Visualizer** | See the difference between BFS and DFS exploration order on a graph (like a game tree). |
